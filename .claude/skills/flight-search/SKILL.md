# UK留学フライト検索スキル

エイジさんの子ども2人（瑛太・梨花）のイギリス寄宿学校 ↔ 日本のフライトを検索・提案するスキル。

## 基本情報

子どもの詳細と学校情報は `references/school-info.md` を参照。年齢は毎年変わるので、検索時の実年齢を計算して使うこと。

| 参照ファイル | 内容 |
|---|---|
| `references/school-info.md` | 子ども・学校の基本情報 |
| `references/um-policies.md` | 航空会社別UMポリシー（便の可否判定） |
| `references/booking-procedures.md` | 予約チャネルとUM申込手順（Step 7で使用） |

**検索は Google Flights（SerpApi MCP）、予約は航空会社直販。** OTA（Kiwi等）は使わない。

## ワークフロー

### Step 1: 学期日程の確認

1. ユーザーが休暇を指定したら（例:「夏休み」「クリスマス」「ハーフターム」）、各学校の公式サイトから該当学期の日程を取得する
   - Gresham's: https://www.greshams.com → Term Dates
   - Oundle: https://www.oundleschool.org.uk → Term Dates
   - WebFetchで取得。取得できない場合はWebSearchで「[学校名] term dates [年度]」を検索
2. 以下を特定する:
   - **学期終了日**（帰国便の出発日の基準）
   - **学期開始日**（渡英便の到着日の基準）
   - **新入生と在校生で到着日が異なる場合はそれも確認**
   - **卒業式・特別行事がある場合はその終了時刻も確認**

### Step 2: フライト日程の決定

学期日程から逆算して各フライトの日程を決める:

**帰国便（UK→日本）:**
- 学期終了日の当日または翌日の午後以降が基本
- 行事（卒業式等）がある場合はその終了後に合わせる
- 2人の学期終了日が異なる場合、遅い方に合わせて同一便で帰国するのが望ましい
- 同一便が無理な場合は別便も検討

**渡英便（日本→UK）:**
- 学期開始日の前日までにLHR着が基本
- 新入生は在校生より1日早い到着が通常
- 瑛太は前泊を避けたい意向あり（ただし無理なら前泊OK）
- 梨花は13歳のため安全重視で直行便（JAL/ANA）が望ましい

### Step 3: 検索条件の設定

**固定条件:**
- 日本側空港: HND（羽田）優先。NRTも許容
- UK側空港: LHR（ヒースロー）指定
- 乗り継ぎ: 最大1回
- 通貨: JPY
- ソート: price優先

**子ども別の条件:**

| | 梨花（年少側） | 瑛太（年長側） |
|---|---|---|
| 渡英便 | **JAL/ANA直行便限定** | 乗継1回OK |
| 帰国便 | 乗継1回OK（兄と一緒なら安心） | 乗継1回OK |
| UM | 年齢に応じて判断（後述） | 通常不要 |

**航空会社のフィルタ:**
- `references/um-policies.md` を読み、搭乗時の実年齢でUM可否を判定
- BAは14歳未満の単独搭乗不可 — 梨花が14歳未満の間は常に除外
- Turkish Airlinesの乗継便は全年齢で同行者必須 — 単独搭乗時は除外
- 13歳の乗継便: Emirates (DXB) と Qatar (DOH) が最も安全

### Step 4: SerpApi（Google Flights）でフライト検索

`mcp__serpapi__search` に `engine: "google_flights"` を指定して使用する。

**基本パラメータ:**

| パラメータ | 値 |
|---|---|
| `engine` | `google_flights` |
| `departure_id` / `arrival_id` | IATAコード（HND, NRT, LHR） |
| `outbound_date` | `YYYY-MM-DD` |
| `type` | `2`（片道）。往復は `1` で `return_date` も指定 |
| `adults` | 人数（**12歳以上は全員 adults**。`children` は2〜11歳のみ） |
| `travel_class` | `1`（エコノミー） |
| `stops` | `2`（乗継1回以下）。直行のみは `1` |
| `currency` | `JPY` |
| `hl` / `gl` | `ja` / `jp` |
| `deep_search` | `true`（精度優先。遅いが結果が正確） |
| `sort_by` | `2`（価格順） |

**任意で使う絞り込み:**
- `include_airlines` / `exclude_airlines`: IATA航空会社コード（例 `JL,NH`、除外 `BA,TK`）
- `max_duration`: 総所要時間の上限（分）
- `layover_duration`: 乗継時間のmin,max（分）— 例 `90,360`

**検索パターン:**

1. **帰国便（2名一緒）**: 片道 LHR→HND、`adults: 2`
2. **梨花 渡英便**: 片道 HND→LHR、`adults: 1`、`stops: 1`（直行のみ）、`include_airlines: "JL,NH"`
3. **瑛太 渡英便**: 片道 HND→LHR、`adults: 1`、`stops: 2`

子ども別に渡英日が異なる場合は片道ずつ検索する方が柔軟。

**返ってくるデータ:**
- **航空会社名・便名（例 JL043）・機材・乗継空港・乗継時間がそのまま返る。** 出発時刻から航空会社を推定する必要はない
- 各候補に `booking_token` が付く。これを `engine: "google_flights"` + `booking_token` で再検索すると予約先の一覧（航空会社直販を含む）が取れる
- 表示価格は**指標**。実売価格は航空会社公式で確認する

**無料枠に注意:** SerpApiは無料250回/月。1回の検索で1消費するため、日付を総当たりせず必要な組み合わせに絞ること。

### Step 5: 結果のフィルタリングと整理

検索結果から以下を除外:
- 乗り継ぎ2回以上
- UMポリシーに抵触する航空会社/ルート
- トランジット12時間超（長すぎ）
- 帰国便で7:00 AM以前のLHR出発（学校からの移動が間に合わない）

残った候補を以下の優先順位でランク:
1. 価格（安い順）
2. トランジット時間（短い順、6時間以内が望ましい）
3. 到着時刻の利便性（宿泊不要で済むか）

### Step 6: 結果の提示

以下のフォーマットで提示する:

```
## [子どもの名前] [往路/復路] 候補

| # | 航空会社/便名 | ルート | 出発→到着（現地時間） | 乗継時間 | 所要時間 | 参考価格 |
|---|--------------|--------|----------------------|---------|---------|---------|
| 1 | JAL JL043 | HND→LHR 直行 | 日時 | — | 総時間 | ¥XXX |
```

各候補について:
- 現地時間で表示（JST/BST/GMT）
- 乗継地と乗継時間を明記
- UM要否と追加料金を注記
- 学校スケジュールとの整合性を確認コメント

最後に**費用総括表**と**要対応事項リスト**を提示:
- 宿泊が必要な箇所（誰が、いつ、どこで）
- 移動手段の手配（LHR→学校のタクシー/レンタカー）
- 学校への確認事項

### Step 7: 予約アクションの提示（このスキルは予約を実行しない）

**このスキルは検索・比較・UM判定までを担い、予約そのものはユーザーが航空会社直販で行う。**
OTA経由の予約はUM受付拒否・発券失敗の原因になるため、いかなる場合も推奨しない。

`references/booking-procedures.md` を読み、候補ごとに**予約アクション**を出す:
- 予約先（航空会社公式URL）
- 予約方法（Web可か電話必須か）— ANA国際線ジュニアパイロットは**電話必須**
- UM申込の要否・方法・期限
- 事前に用意すべき情報（お迎え担当者の氏名・連絡先など）

Google Flightsの `booking_token` から予約先一覧を引ける場合は、その中の**航空会社直販**を優先して提示する。OTAしか出ない候補は、その旨を明記して優先度を下げる。

### Step 8: 確定後の保存

ユーザーがプランを確定したら `workspace/` に保存:
- ファイル名: `YYYY-MM-DD_[holiday]-flights-plan.md`
- 便名、航空会社、日時、参考価格、予約先URL、UM申込手順、アクション項目を含める

## エアラインの好み（過去の利用実績）

- Finnair（HEL経由）: 家族で利用実績あり
- JAL（直行）: 利用実績あり
- ANA: 利用実績あり
- BA: メンバーシップあり（ただし梨花が14歳未満の間は利用制限あり）
- Emirates（DXB経由）: コスパが良く乗継もスムーズ

## 重要な制約（変更があれば更新）

- **OTA（Kiwi/Expedia/Trip.com等）では予約しない。** UM受付拒否・発券失敗の原因になる（Kiwiは2026年8月に廃止済み）
- 梨花が14歳になるまでBAは単独搭乗不可
- 梨花の渡英便はJAL/ANAの直行便を最優先
- 2人の帰国便は同一便が望ましい（年少の梨花の安全のため）
- トランジットは6時間以内が望ましい（9時間超は避ける）
- 前泊なしが理想だが、コストが大幅に上がるなら前泊OK
